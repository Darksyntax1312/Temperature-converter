🌡️ Temperature Converter

A sleek and intuitive web application for quick temperature conversions between Celsius and Fahrenheit.

✨ Features

    Real-time Conversion – Convert temperatures instantly with a single click

    Two-Way Conversion – Convert from Celsius to Fahrenheit and vice versa

    Clean UI – Modern, minimalistic design with smooth animations

    User-Friendly – Simple input field and dropdown selection

    Responsive – Works well on both desktop and mobile devices

💻 Usage

    Enter the temperature value in the "Degrees" input field

    Select the unit type (Celsius or Fahrenheit) from the dropdown

    Click the "Convert" button

    View the converted result instantly

Conversion Formulas Used

    Celsius to Fahrenheit: (°C × 9/5) + 32 = °F

    Fahrenheit to Celsius: (°F − 32) × 5/9 = °C
